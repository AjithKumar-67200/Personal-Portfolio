# Ajith Kumar S — Portfolio

Next.js upgrade of the Personal Portfolio, preserving all professional content from the existing site.

## Review locally

```bash
cd site
npm install
npm run dev
```

Open http://localhost:3000

The legacy site remains in `../Personal-Portfolio` until this build is approved for replacement.

## Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
